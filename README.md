# 📦 Barcode Generator (Next.js)

A sleek and efficient barcode generator built with **Next.js**.  
Easily generate and download barcodes from any input using modern web technologies.

🔗 **Live Demo:** [DemoUrl](https://label-barcode.netlify.app/)  
🧰 **Tech Stack:** Next.js · React · JsBarcode · Tailwind CSS

---

## ✨ Features

- 🔤 Input any text or number to generate barcodes
- 📄 Supports popular barcode formats (CODE128, EAN, UPC, etc.)
- 🎨 Download barcodes as PNG or SVG
- 🌓 Clean, responsive UI with optional dark mode
- ⚡ Lightning-fast performance with Next.js

---

## 🛠️ Built With

- [Next.js](https://nextjs.org/) — Framework for SSR and static site generation
- [React](https://reactjs.org/)
- [JsBarcode](https://github.com/lindell/JsBarcode) — Barcode rendering library
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first styling
